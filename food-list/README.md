# Food List

A small React app that displays favorite foods and lets you select one to show
an "I love ..." message.

## Features

- Shows Pizza, Biriyani, and Burger in a simple card.
- Select **Love** beside a food to update the message.
- Uses Bootstrap for button styling.

## Run locally

From this directory, install the dependencies and start the development server:

```bash
npm install
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000).

## Available scripts

- `npm start` — run the development server.
- `npm test` — run the tests.
- `npm run build` — create an optimized production build in `build/`.
