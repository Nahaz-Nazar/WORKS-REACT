# Book Manager App

## Project Description

Book Manager App is a React application used to manage books. It allows users to add, view, edit, and delete book details using a REST API.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- REST API
- Fetch API

## API URL

`https://worksheet-library.mashupstack.com/books`

## Book Details

The application manages the following fields:

- **Title** – Book title
- **Author** – Author name
- **Published Year** – Year of publication
- **Genre** – Book category

## Features

1. **Create Book:** Add a new book using the form.
2. **View Books:** Display all books in a table.
3. **Edit Book:** Update the details of an existing book.
4. **Delete Book:** Remove a book from the list.
