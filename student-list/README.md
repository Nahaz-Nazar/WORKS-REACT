# Student List Management SPA

## Project Description

A React-based Single-Page Application for managing student records.

## Features

- Add new students.
- Validate required fields.
- Ensure unique roll numbers.
- Display students in a table.
- Edit student details inline.
- Save or cancel edits.
- Delete student records.
- Search students by name in real time.
- Display "No students found" when no matching records exist.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS

## Installation and Setup

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:

   ```bash
   npm.cmd install
   ```

4. Start the application:

   ```bash
   npm.cmd start
   ```

5. Open `http://localhost:3000` in your browser.

## Student Fields

- ID
- Student Name
- Roll Number
- Class

## Conclusion

This project demonstrates React state management, form validation, list rendering, inline editing, deletion, and real-time searching in a Single-Page Application.

Note: Student records are stored in React state and are not persisted after a browser refresh.
