# Welcome Message

## Description
A simple React application that displays a welcome message on the screen and logs a message to the browser console when the page loads for the first time.

## Features
- Displays the text: **Hello, user! Welcome to our site.**
- Uses the `useEffect()` hook.
- Displays **Welcome message displayed.** in the browser console.
- No buttons or user interactions.
- Uses an empty dependency array to run the effect after the initial render.

## Technologies Used
- React.js
- JavaScript
- CSS
- HTML

## Output

**Screen Output:**
Hello, user! Welcome to our site.

**Browser Console Output:**
Welcome message displayed.

## How to Run the Project

1. Open Command Prompt.
2. Navigate to the project folder:

   cd /d D:\REACT-Node.js\welcome-message

3. Install dependencies if needed:

   npm install

4. Start the application:

   npm start

5. Open `http://localhost:3000` in your browser.
