# Profile Card - React

This project is a simple Profile Card web page created using React and Bootstrap.

The card displays a person's name, a short description, one internal image, and one external image.

## Features

* Person's name stored in a variable
* Description stored in a variable
* Bootstrap used to center the card
* Internal CSS used for border, padding, background color, and styling
* Internal/local image displayed from the project folder
* External image displayed using an online image URL
* Bootstrap `img-fluid` class used for responsive images

## Technologies Used

* React
* Bootstrap
* JavaScript
* CSS

## Installation

Open the terminal inside the `profile-card` project folder.

Install the required packages:

bash
npm.cmd install


Install Bootstrap:

bash
npm.cmd install bootstrap


## Run the Project

Start the React application:

bash
npm.cmd start


The application will open in the browser.

You can also open:

text
http://localhost:3000


If port 3000 is already in use, choose `Y` when React asks to use another port.
